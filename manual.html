操作手冊

「Where-What-How 商業策略工作室」把一個商業議題拆解成三個構面：Where（要鎖定什麼戰場）／What（該建構什麼致勝模式）／How（該如何具體落地）。每個構面內部借用六頂思考帽的六種視角——事實、風險、機會、創意、情感、整合結論——交叉檢視，幫你把該想清楚的策略想清楚，最後再把三個構面的結論整合成一段完整的策略陳述。

什麼是 Where / What / How

  • Where 戰場：這個議題該優先鎖定哪個範圍——哪個市場、客群、地理區域或通路，才是資源打得動、又真正存在機會的戰場？貪心想覆蓋所有範圍，往往哪一群人都打不動。
  • What 致勝模式：在選定的戰場裡，該建構什麼樣的核心價值主張、差異化打法或商業模式，才有機會真正勝出，而不只是複製既有做法？
  • How 落地方式：這個致勝模式該怎麼具體執行——需要哪些關鍵行動、資源配置與時程安排，才能從構想真正走到落地？
三個構面有先後順序——先收斂戰場，再設計致勝模式，最後才談如何落地。跳過前面直接想「怎麼做」，常常是因為戰場或致勝模式根本還沒想清楚。

六角度分析是什麼

每個構面產生分析時，工具會借用六頂思考帽的六種視角交叉檢視同一個問題，避免只看到單一角度：

  • 事實盤點（白帽）：目前客觀存在的現況是什麼？
  • 風險提醒（黑帽）：貿然行動可能踩到的坑或風險是什麼？
  • 樂觀機會（黃帽）：這裡面藏著什麼值得期待的正向機會？
  • 創意替代（綠帽）：有沒有跳脫常規、值得一試的另一種做法？
  • 情感直覺（紅帽）：面對這個決定，直覺上的擔心或期待是什麼？
  • 整合結論（藍帽）：綜合前五個角度，收斂出的具體建議是什麼？
六頂思考帽在這裡不是獨立的功能分頁，而是內嵌在每個構面分析裡的視角來源——你會看到 5 張角度小卡加上 1 張比較顯眼的「整合結論」卡，而不是要你自己套用六頂帽子分開操作。

操作步驟

  1. 在最上方「商業議題基本資料」填入議題名稱、產業／情境、現況背景、期望目標，或直接點下方 5 組內建範例快速開始
  2. 切到「Where｜戰場」分頁，可選填「目前考慮的戰場範圍」「資源或範圍限制」補充脈絡，按「✨ 產生 Where 分析」，零金鑰也能立即產出六角度分析
  3. 依序切到「What｜致勝模式」「How｜落地方式」分頁，各自填選填欄位並按「產生分析」——三個構面彼此獨立，可以任意順序產生
  4. 三個構面都產生結果後，切到「整合建議」分頁按「🧭 產生整合建議」，會把三個構面的「整合結論」拼接（或選用 AI 潤飾）成一段完整的策略陳述
  5. 完成後可「匯出 TXT」或「匯出 PDF」把完整分析（含六角度細節與整合建議）存成檔案
所有內容自動存在這台瀏覽器的 localStorage，重新整理頁面不會遺失；不同電腦或清除瀏覽器資料就會不見，請自行下載 .txt 備份重要內容。

AI 功能（選用，需自備 API 金鑰）

展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID。

  • 沒填金鑰時，每個構面的「產生分析」都會用規則式引擎（依產業關鍵字分類＋內建模板）立即產出完整的六角度分析，不需要等待，也不會有任何 API 費用
  • 填了金鑰後，「產生分析」會改連線到你選擇的服務商，讓 AI 依你填寫的議題細節與補充脈絡重新生成六個角度的內容
  • AI 若只有部分角度回應失敗或格式不對，工具會自動把那幾個角度個別退回規則式版本補上，並在結果上方標示「🧩 AI＋規則式混合版本」與缺漏項目，不會整批放棄重來
  • 整合建議分頁的「AI 潤飾成一段流暢文字」會把三個構面的結論送給 AI 整合成一段完整陳述，失敗時自動退回規則式拼接版本
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。
